# 爆款提詞器

給自己用的人設草稿工具。先選定產業，再把說話方式收成一段可以貼給 AI 的提示詞。不直接產生腳本。

可切換兩種產業，資料分開存在每一份人設裡：

- **保險業務**：理賠故事、醫療險觀念、長照／退休、傳承與稅務常識、家庭保障檢視、理財常識、業務日常、增員、生活興趣。提示詞帶保險溝通的合規界線（不推薦商品、不承諾報酬、不點名保險公司、不教避稅、不留電話、提醒以保單條款為準、呼籲用「我們」）。
- **其他行業**：美業、餐飲、房產、教育課程、健身、電商、設計工作室、心靈成長、生活風格，另有「我的產業」自由填寫。只用一般創作者界線（不保證、不誇大效果、遵守平台規則），不會套進保險用語。

預設是空白人設。選了「保險業務」之後，才看得到「套用 Show 範例」（秀老闆／藝世錄團隊長，昶勝軍，不含公司名稱與電話）。

頁面含 `<meta name="robots" content="noindex,nofollow">`，站點根目錄的 `robots.txt` 為 `Disallow: /`。資源用相對路徑，可放在網站根目錄。

## 本機預覽

```bash
npm start
```

瀏覽器打開 http://127.0.0.1:44741/

靜態檔是根目錄的 `index.html` 與 `assets/`。用系統字型，沒有外部字型請求。

## 稽核

舊站「爆款製造機」的稽核留在 `audit/`（報告 `audit/AUDIT.md`，快照 `audit/fixtures/`，舊截圖 `audit/original-shots/`）。

新工具的回歸測試：

```bash
npm install
npm run audit
```

會用無頭 Chromium 跑 390×844 與 1280×800，結果寫進 `audit/verify-shots/`。舊站稽核腳本是 `npm run audit:legacy`。
